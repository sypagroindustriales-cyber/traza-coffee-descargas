# Traza Coffee · descargas

Aquí están **solo** los instaladores de la última versión de Traza Coffee (el código del programa es privado):

- `Instalador_TrazaCoffee_X.Y.Z.exe`: programa del PC de la oficina.
- `Instalador_TrazaCoffee_Campo_X.Y.Z.exe`: Traza Coffee Campo (app de escritorio para productores y técnicos).
- `TrazaCoffee_App_X.Y.Z.apk`: app Android (técnico y productor).
- `version.json`: la última versión y la huella SHA-256 de cada archivo. El botón «Buscar actualización» del programa y de las apps lee este archivo.

El programa necesita un código de activación para funcionar.
